# Design do PARTYVERSE
- Cooperação obrigatória e legível: tarefas que exigem 2 pessoas, funções diferentes, informação dividida.
- Escala por jogadores muda o desenho: 2 = dupla compacta; 4 = equipe pequena com divisão de tarefas; 6+ = tarefas simultâneas em locais diferentes; 8–10 = mapa maior e funções extras.
- Dificuldade: Fácil = mais tempo + dicas visuais; Médio = equilibrado; Difícil = menos tempo, eventos extras e exigência de coordenação.
- Toda experiência tem: objetivo principal, secundários, vitória, derrota, pontuação (1–3 estrelas), feedback visual e sonoro, reinício ("Jogar de novo").
- Arte: 3D estilizado consistente com os kits Kenney + peças procedurais arredondadas (`rbox`), paleta vibrante (violeta #7c5cff, rosa #ff4fa3, laranja #ff8a3d, amarelo #ffc93c), UI com Lilita One.
